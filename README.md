# ✅ Todo List

A simple to-do list where you can add items, check them off, delete individual items, and clear the whole list. Built with HTML, CSS, and Vanilla JavaScript.

### Project Description

This project is a simple to-do list application. It allows the user to type a task and a button to add it to the running to-do list. The list items will render each task as a list item with a checkbox and the user has the ability to delete a single item or wipe the whole list at once. Checking a box strikes the task through so finished items are easy to spot. This project was originally forked from [Resilient-Labs/todo-list-2019-week05](https://github.com/Resilient-Labs/todo-list-2019-week05).

### Features:

- **Add items** — type a task into the input and add it to the list.
- **Check items off** — each item has a checkbox that adds a strikethrough when checked.
- **Delete individual items** — remove a single task without touching the rest of the list.
- **Delete all** — clear the entire list in one click.
- **Static web application** — one `index.html`, no build step, no dependencies to install.

### Tech Used:

- **Frontend:** HTML, CSS, JavaScript (vanilla, no framework)
- **DOM APIs:** `document.createElement`, `appendChild`, `prepend`, `addEventListener`
- **Styling in JS:** `style.textDecoration` for the checked-off look
- **Fonts:** Honk
- **Hosting:** GitHub Pages
